# PERCEPTUAL INTEGRITY MEASURE (PIM) Using SECOND Features Set
PERCEPTUAL INTEGRITY MEASUREC (PIM) a knowledge - driven no- reference quality measure that adaptively assesses image integrity across diverse degradation. PIM is
computed from the SECOND feature set, comprising Sharpness, Exposure, Contrast, Opponent Colourfulness, Noise, Detail
and texture (SECOND). In PIM-SECOND, a conditional environmental penalty is introduced to account for hazy degradations, in addition to adaptive weights that depend on the mean luminance. Furthermore, the PIM can be tailored to user- or application-specific requirements by allowing users to define task-oriented standards. Using the SECOND feature set, users can compute a quality score and compare the resulting outcomes against their own application-specific requirements.
